## 🏗️ Architecture & Projects

**[Vaulted](https://tyrakj.vercel.app)**
> Gasless freelance escrow on Base Sepolia. Payment locks on-chain at job creation, releases on client approval, with a 7-day auto-release dispute mechanism.
> <br/>*Stack: Solidity, OpenZeppelin, ethers.js, React*

**[Agentic Commerce Gateway](https://tyrakj.vercel.app)**
> AI shopping assistant routing natural-language and handwritten orders across 11 Indian languages via LangChain + Sarvam LLMs, with Twilio and Paytm integration.
> <br/>*Stack: FastAPI, LangChain, React, PostgreSQL*

**[CodeSheriff](https://tyrakj.vercel.app)**
> 4-layer code security pipeline: prompt-injection detection, credential leak scanning, AST-based hallucination checks, immutable audit trail, IBM watsonx.ai for Java analysis.
> <br/>*Stack: Spring Boot, IBM watsonx.ai, JavaParser, JWT*

**[API Guardian](https://tyrakj.vercel.app)**
> Non-blocking API gateway with Kafka event streaming, Redis-backed rate limiting, Resilience4j circuit breakers, JWT auth, and a live React SSE dashboard.
> <br/>*Stack: Spring Boot, Kafka, Redis, Resilience4j*
