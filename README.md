### ✧ Recent Work

*   **Vaulted** — Gasless freelance escrow on Base Sepolia. Payment locks on-chain at job creation, releases on client approval, with a 7-day auto-release dispute mechanism. <br/>
    `Solidity` · `OpenZeppelin` · `ethers.js` · `React`
*   **Agentic Commerce Gateway** — AI shopping assistant routing natural-language and handwritten orders across 11 Indian languages via LangChain + Sarvam LLMs, with Twilio and Paytm integration. <br/>
    `FastAPI` · `LangChain` · `React` · `PostgreSQL`
*   **CodeSheriff** — 4-layer code security pipeline: prompt-injection detection, credential leak scanning, AST-based hallucination checks, immutable audit trail, IBM watsonx.ai for Java analysis. <br/>
    `Spring Boot` · `IBM watsonx.ai` · `JavaParser` · `JWT`
*   **API Guardian** — Non-blocking API gateway with Kafka event streaming, Redis-backed rate limiting, Resilience4j circuit breakers, JWT auth, and a live React SSE dashboard. <br/>
    `Spring Boot` · `Kafka` · `Redis` · `Resilience4j`
